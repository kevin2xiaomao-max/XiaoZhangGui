# 图片与文件逐次外发确认

按正式开发指令“文件和图片外发逐次确认”修正旧偏好绕过路径。每次选择后只存待确认内容；仅点发送调用 analyze，取消清除待确认内容。移除“以后直接发送”和关闭确认的 UI；保留旧 UserDefaults 字段兼容，不迁移业务数据，也不删除原偏好持久化测试。

源码门禁增加：不再读取跳过确认的旧偏好、图片/文件各只有确认发送函数调用 analyze、取消入口清除内容、设置不存在关闭入口。Provider、Keychain、模型、Repository、执行日志均未改。

真实相册/文件服务外发及取消网络抓包仍需设备验收，不以源码门禁冒充真机测试。

复验：13 单测、1 UI 全部通过（Consent-final.xcresult）。首轮 UI 仍要求旧可关闭开关而失败，已按逐次确认规范升级断言，保留失败日志。
