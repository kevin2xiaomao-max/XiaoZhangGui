# 第 5–8 步：任务、配送、日历和扩展页

## 实现范围

- 待办进度使用可缩放衬线数值，文字绿与图形绿分流；保留今天/明天/逾期/已完成/备忘五组、两段式完成、失败重试。
- 客户配送主按钮采用深绿白字。继续使用待处理/配送中/已完成三状态、配送时间、地址复制、编辑和推进动作；不引入原型中的第四状态。
- 日历补齐定稿金色、日历可读操作金、衬线日期头；月/周密度、锚点、ghost、状态点、AX3 纵向日期列表保留。V4 调用点 Reduce Motion 使用 nil。
- 商品价格/统计、临期统计、日报、Widget 营业额统一字体与局部纸面。备忘标题明确为“备忘记录”，时间标为“更新于”，避免把更新时间误认成任务执行时间。
- 设置沿用已有原生分组与共享 Fusion 画布；提醒时间、备份预览/追加恢复、Keychain、主题/壁纸保留。未新增设置入口。
- 扩展页既有 GroupSurface/WorkRow/StatusBadge 继续复用，未重建业务层。Widget 主屏、锁屏、StandBy 需独立设备验收。

## 三页面交互梳理

待办与日历操作同一 Todo；备忘仍为独立 Memo。显示优化只明确页面职责和更新时间，不创建副本、自动转任务、改变日期归属或修改 schema。三组筛选、备忘转任务等方案仍不实施，见 THREE-PAGE-REVIEW.md。
