# 「你的小掌柜」Android V3.7.1（build 37）OPPO 安装指南

> 版本：3.7.1 / build 37（versionCode 37）
> 目标设备：OPPO PKJ110，ColorOS 17（免 Root，无需解锁、无需刷机）
> 真机验收状态：PKJ110 真机项当前一律 **NOT RUN**；本指南中的 ColorOS 菜单名为通用写法，实际菜单以真机为准（见 `ANDROID_V371_OPPO_VERIFICATION.md` §3.1 约束）。

---

## 0. 免 Root 声明

- 本应用**不需要 Root**，不申请、不依赖任何 Root 权限。
- 仅通过系统标准安装包（APK）侧载安装，所有功能（记账、待办、提醒、语音、AI）均在普通应用权限下工作。
- 不需要刷机、不需要关闭任何系统安全开关（如"允许调试"之外的选项）。

---

## 1. 安装步骤（侧载 APK）

### 1.1 允许"安装未知应用"

1. 打开 **设置** → **安全**（或「密码与安全」）→ **安装未知应用**（部分版本在「设置 → 应用 → 特殊应用权限 → 安装未知应用」）。
2. 找到你要用来打开 APK 的应用（**浏览器** 或 **文件管理**），将其开关设为 **允许**。
3. 一次授权后，后续同应用来源的 APK 可重复安装，无需每次再授权。

### 1.2 安装 APK

1. 用已授权的浏览器/文件管理打开 APK 文件，点击 **安装**。
2. 若系统提示"可能存在风险"，这是 Android 对未知来源包的标准提示；请确认 APK 来自可信渠道后继续。
3. 安装完成后可直接打开，或从桌面图标进入。

### 1.3 首次启动

1. 首次打开 App，按提示完成必要权限（见 §3），全部权限**均可稍后在系统设置中补授权**，不授权也能先用核心记账功能。
2. App 无强制登录、无账号体系，数据保存在本机（Room 数据库），卸载 App 会连数据一起删掉——**重要数据务必先走 §2 备份流程**。

## 2. 旧包签名冲突：无损升级流程（重要）

**核心规则：签名不一致的包绝对不能直接覆盖安装**（Android 系统会拒绝安装，强行卸载旧包会丢失数据）。

### 2.1 先查签名是否一致

任选其一：

- **adb 方式**（电脑已装 adb）：`adb shell dumpsys package com.xiaozhanggui.app | grep signatures`，对比已安装包与新 APK 的签名指纹是否一致；
- **手机方式**：用 APK 分析类 App 打开新旧两个 APK，查看签名证书 SHA-256 指纹是否相同。

### 2.2 签名一致 → 直接覆盖升级

签名一致且新包 versionCode 更高时（build 37 ≥ 37），可直接安装覆盖：**应用数据完整保留**，无需任何操作。

### 2.3 签名不一致 → 先备份，绝不直接卸载旧包

1. 在**旧包**内：首页头像 → 个人中心 → **备份** → 导出 `xiao-zhang-gui-backup.json`（每次导出会覆盖上一次），把文件保存到电脑或云盘。
2. **不要卸载旧包**，直到新包确认可用且数据恢复成功。
3. 安装新包（并存过渡方案：可用 `applicationIdSuffix ".v371"` 构建的并存包实现双包并存，旧包不受影响）。
4. 在新包内走**恢复**流程导入备份 JSON（恢复=**追加**不清空，恢复后三类通知会自动重建）。

### 2.4 关于签名丢失

- 最终正式包使用**持久可复用的正式签名证书**（密钥不上仓库，见 `ANDROID_V371_OPPO_VERIFICATION.md` §7）。
- **签名证书一旦丢失，该签名下的包永远无法再覆盖升级**（只能卸载重装 + 备份恢复）。请务必妥善保管 keystore 文件及密码。

## 3. 权限说明与引导

### 3.1 通知权限（Android 13+）

- App 会在需要时申请 **POST_NOTIFICATIONS** 运行时权限（待办到期、临期、客户跟进提醒）。
- **拒绝后**：提醒功能不会崩溃，但待办/临期/客户提醒将**仅在应用内显示**，提醒设置页会明确标注"通知未授权"（降级说明）。
- 补授权路径：设置 → 通知与状态栏 → 通知管理 → 「你的小掌柜」→ 允许通知。

### 3.2 精确闹钟（SCHEDULE_EXACT_ALARM，特殊权限）

- 提醒准时触发依赖 **SCHEDULE_EXACT_ALARM**（本 App 已按合规要求**移除 `USE_EXACT_ALARM`**，仅保留此用户可撤销的特殊权限）。
- **被拒绝/未授权时**：提醒会自动降级为**非精确提醒**（可能延迟几分钟送达），提醒设置页会诚实显示"非精确提醒"，**不会谎报精确**。
- 补授权路径：设置 → 应用 → 特殊应用权限 → 闹钟和提醒 → 「你的小掌柜」→ 允许。

### 3.3 麦克风权限（语音输入）

- 语音入口（个人中心 → 语音输入、AI 面板语音按钮）需要 **RECORD_AUDIO**。
- **首次拒绝**：入口降级为文字输入，并提示去系统设置开启；**永久拒绝（"不再询问"）**：入口保持明确的失败态，提供"前往系统设置"引导，不静默失败。
- 无 GMS 的设备（如部分国行 OPPO）：`SpeechRecognizer` 可能不可用，此时语音入口会自动降级为文字输入并给出明确提示（**不会假装可用**）。

### 3.4 省电/后台相关（ColorOS 提醒不被杀掉的关键）

- **自启动管理**：设置 → 应用管理 → 自启动管理 → 找到「你的小掌柜」→ 允许自启动（杀进程后通知仍能触发的前提）。
- **省电策略**：设置 → 电池 → 应用耗电管理 → 「你的小掌柜」→ 允许后台活动 / 允许完全后台行为。
- **锁定后台**：多任务界面下拉「你的小掌柜」卡片 → 锁定（防止被一键清理）。

## 4. 下次更新说明

- **同签名 + 更高 versionCode**：可直接覆盖升级，数据保留。
- **签名证书更换**：等同于换了一个 App，无法覆盖安装，必须走 §2.3 备份→恢复流程。
- 建议每次大版本升级前都先做一次备份导出（`xiao-zhang-gui-backup.json`），有备无患。

---

## 5. 语言与深色模式

- **应用语言**：跟随系统语言（暂无应用内语言切换开关）；语音识别语言可在「个人中心 → 语音输入」里选择**普通话 / 粤语**。
- **深色模式**：「个人中心 → 外观/主题」提供**跟随系统 / 浅色 / 深色**三档；壁纸在深色模式下会自动增强遮罩以保证文字可读。
- 壁纸保存在本机，不会上传。

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 安装时提示"应用未安装"/签名冲突 | 见 §2：先查签名，签名不一致走备份→恢复，**不要直接卸载旧包** |
| 提醒不准时/收不到 | 先检查 §3.2 精确闹钟授权，再检查 §3.4 自启动与省电策略 |
| 语音按钮灰色不可点 | 设备无可用 ASR（无 GMS）或麦克风被永久拒绝，见 §3.3 |
| 首页天气显示占位 | 天气功能为占位实现（真实 API 待后续版本），见 Release Notes 已知问题 |
| 升级后数据不见了 | 若为卸载重装：用 §2 的备份 JSON 恢复；若为覆盖升级且签名一致：数据应保留，如异常请保留现场并反馈 |
